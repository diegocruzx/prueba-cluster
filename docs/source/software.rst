Software de Desarrollo y Simulaciones
=====================================

.. list-table:: 
   :widths: 20 80
   :header-rows: 0
   :class: software-table floating-table

   * - .. image:: _static/abinit_logo.png
          :width: 100%
          :align: center
          :alt: Logo Abinit

     - **Abinit**
       
       :Descripción: Suite de software para calcular propiedades ópticas, mecánicas y vibratorias de materiales mediante DFT.
       :Capacidades: Cálculo de moléculas, nanoestructuras y sólidos de cualquier composición.
       :Documentación: `Sitio Oficial <https://www.abinit.org/>`_

.. list-table:: 
   :widths: 20 80
   :header-rows: 0
   :class: software-table floating-table

   * - .. image:: _static/quantum_espresso_logo.png
          :width: 100%
          :align: center
          :alt: Logo Quantum ESPRESSO

     - **Quantum ESPRESSO**
       
       :Descripción: Suite integrada de código abierto para cálculos de estructura electrónica y modelado de materiales a nanoescala.
       :Método: Basado en la teoría funcional de la densidad (DFT), ondas planas y pseudopotenciales.

.. list-table:: 
   :widths: 20 80
   :header-rows: 0
   :class: software-table floating-table

   * - .. image:: _static/vmd_logo.png
          :width: 100%
          :align: center
          :alt: Logo VMD

     - **VMD (Visual Molecular Dynamics)**
       
       :Descripción: Programa de visualización y análisis de trayectorias de dinámica molecular.
       :Aplicaciones: Análisis estructural, animaciones moleculares, representaciones gráficas avanzadas.
