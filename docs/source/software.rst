Software de Desarrollo y Simulaciones
=====================================

A continuación se detalla el catálogo de software científico, librerías y herramientas de desarrollo disponibles en el cluster Leviatán.

.. note::
   Si requieres una versión específica no listada aquí, por favor contacta a soporte.

Ciencia de Materiales y Física
==============================

.. list-table:: 
   :widths: 20 80
   :header-rows: 0
   :class: software-table

   * - .. image:: _static/abinit_logo.png
          :width: 100%
          :align: center
          :alt: Logo Abinit

     - **Abinit**
       
       :Descripción: Suite de software para calcular propiedades ópticas, mecánicas y vibratorias de materiales. Utiliza ecuaciones de la teoría funcional de la densidad (DFT).
       :Capacidades: Cálculo de moléculas, nanoestructuras y sólidos de cualquier composición.
       :Documentación: `Sitio Oficial <https://www.abinit.org/>`_ | `Manual de Usuario <https://docs.abinit.org/>`_
